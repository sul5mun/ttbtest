# رتّبها | RoomCheck

واجهة تجريبية عربية لتقييم ترتيب الغرف. افتح `roomcheck/index.html` مباشرةً أو عبر استضافة ثابتة.

**مهم:** الواجهة الثابتة تعرض صورًا مختارة محليًا وتقريرًا توضيحيًا فقط؛ لا تقوم بتحليل الصور فعليًا. التحليل الحقيقي متاح في نسخة Flask المحلية المنفصلة ويتطلب OpenAI API واستضافة للخادم. لا تضع مفتاح API في ملفات المتصفح.

تضم الواجهة اختيار المهمة، رفع الصور محليًا، معاينة الصور، ومثال تقرير مفصل مع توصيات.
